🔬 Methodologie

Generation des donnees

Procedure SP_GENERER_JEU_DE_TEST : donnees realistes pour 2 sites (Cergy/Pau) avec noms, serials, FK coherentes.

Protocole de test

Chaque requete executee 5 fois, temps moyen retenu. Cache Oracle vide entre les scenarios.

Scenario A : Sans index

Tous les index rendus INVISIBLE. Full Table Scan systematique.

Scenario B : Avec index

Index VISIBLE : B-Tree, composites, fonctionnels (UPPER), bitmap. Vues optimisees.
